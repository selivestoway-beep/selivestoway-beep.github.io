# Импорт персонажей «Кодекса Термины»

Эта функция позволяет добавить статьи и портреты из **локального JSON-пакета** через браузер без публикации незашифрованного текста на GitHub. Пользователь предоставляет пакет на своём компьютере. В GitHub записываются изображения и зашифрованный файл `data/articles.enc.json`; история статьи обновляется через существующий механизм вики.

## Как добавить Алистера и Иммору

1. Получите файл `Кодекс_Термины_Алистер_Иммора.json` из переписки с ChatGPT. **Не добавляйте его в публичный репозиторий**: внутри есть читаемый текст статей.
2. Дождитесь объединения этого Pull Request с веткой `main` и обновления сайта GitHub Pages.
3. Откройте [Кодекс Термины](https://selivestoway-beep.github.io/) и разблокируйте энциклопедию обычным ключом.
4. Перейдите в «Вход для ГМа», авторизуйтесь с GitHub-токеном, имеющим запись в репозиторий, и выберите «Импорт персонажей».
5. Укажите скачанный JSON. Проверьте предварительный список: категория, адрес страницы, новая запись или замена существующей.
6. Нажмите «Сохранить персонажей в зашифрованной вики». Дождитесь подтверждения каждой записи. В случае ошибки данные, уже записанные успешно, не откатываются автоматически; повторная попытка пропускает успешно импортированные статьи.
7. Проверьте `#pontifik-alister` и `#immora` в браузере. Дайте GitHub Pages время обновить опубликованную версию.

### Особенности

- Если статья с таким идентификатором существует, **её текст, портрет, краткое описание и связи заменяются**. Другие данные и дата создания сохраняются. История правок сохраняется.
- Если тот же адрес занят другим персонажем или имя дублируется в другой статье, импорт остановится без записи.
- Для портретов используются исходные изображения, предоставленные вместе с текстами; файлы сохраняются в GitHub без перекодирования, уменьшения или сжатия.
- Файл JSON содержит текст в **незашифрованном** виде, поэтому не отправляйте его в публичные места. Тексты шифруются **в браузере** прежде, чем попасть в `articles.enc.json`; изображения не шифруются.
- Утилита не просит передавать ключ или токен через переписку. Используется тот же вход, что в редакторе сайта.
- Импорт не требует принятия PR #1–3; это независимая функция, добавленная поверх `main`.

## Формат файла

Корень JSON: `{ "format": "kodeks-terminy-characters", "version": 1, "articles": [...] }`. Каждая запись содержит `slug`, `kind: "character"`, `title`, `group`, `role`, `summary`, `body`, необязательные `aliases`, `status`, `facts`, `relations` и `image: { filename, mime, base64 }`. Файл читается только локально и не отправляется в репозиторий.
